# Quiz - Conhecimentos Gerais

## Integrante
Diego Yuk Fialho Soares

## Trilha
Desenvolvimento Mobile

## Tema do Quiz
Conhecimentos Gerais

## Exemplo de pergunta
Qual é a capital do Brasil?

A) São Paulo  
B) Brasília  
C) Rio de Janeiro  
D) Salvador  

Resposta correta: B) Brasília.

## Utilização da Inteligência Artificial
A Inteligência Artificial foi utilizada como apoio na criação das perguntas, organização do código e esclarecimento de dúvidas durante o desenvolvimento do projeto.

## Como executar o jogo
1. Abra o projeto no Visual Studio Code.
2. Abra o terminal na pasta raiz do projeto.
3. Execute o comando:

```bash
dart run
```
